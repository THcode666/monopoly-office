# 如何自定义数值与文案

所有可调内容都在 `data/` 目录下的 8 个 JSON 文件里，**改完刷新页面即生效，不用动任何代码**。

> 改完记得重新构建单文件版：`node tools/build.mjs`

---

## 一、快速对照表

| 想改什么 | 改哪个文件 | 哪个字段 |
|---|---|---|
| 初始现金、利率、房价升值 | `config.json` | `economy.*` |
| 职级工资系数、晋升门槛 | `config.json` | `ranks[]` |
| 回合数、每月回合数 | `config.json` | `game.maxRounds` / `roundsPerMonth` |
| 破产宽限期、变卖顺序 | `config.json` | `game.bankruptcy.*` |
| 获胜条件 | `config.json` | `winCondition` |
| 地图格子、房价、地形 | `board.json` | `tiles[]` / `decor[]` |
| 格子事件文案与效果 | `events.json` | `pools.<类型>[]` |
| 机会卡 / 命运卡 / 道具卡 | `cards.*.json` | `cards[]` |
| AI 性格与权重 | `ai_profiles.json` | `profiles[]` |
| 界面文案 | `ui_text.json` | 各节 |

## 二、最常改的几个

### 初始现金

```jsonc
// config.json
"economy": {
  "initialCash": 20000,   // ← 改这里
}
```

### 职级系数与门槛

```jsonc
"ranks": [
  { "id": "intern",     "name": "实习生", "coefficient": 0.6, "minNetWorth": 0 },
  { "id": "specialist", "name": "专员",   "coefficient": 1.0, "minNetWorth": 60000 },
  { "id": "supervisor", "name": "主管",   "coefficient": 1.4, "minNetWorth": 120000 },
  { "id": "manager",    "name": "经理",   "coefficient": 2.0, "minNetWorth": 200000 },
  { "id": "director",   "name": "总监",   "coefficient": 3.0, "minNetWorth": 320000 }
]
```

- `coefficient` = 工资倍数（乘在 `baseSalary` 上）
- `minNetWorth` = 净资产达到多少自动升职
- 必须**递增**，校验器会拦

### 利率

```jsonc
"economy": {
  "depositInterestRate": 0.004,   // 存款月息 0.4%
  "loanInterestRate":   0.012,   // 贷款月息 1.2%
  "mortgageRatio":      0.7,     // 贷 70%，首付 30%
  "mortgageMonths":     36,      // 房贷 36 期
  "vehicleMonths":      24,      // 车贷 24 期
  "propertyAppreciation": 0.012  // 房产月升值 1.2%
}
```

### 房价与租金

在 `board.json` 里找 `type` 为 `property` 或 `company` 的格子：

```jsonc
{
  "id": 10,
  "type": "property",
  "name": "老公房",
  "grid": [10, 10],
  "payload": {
    "price": 34000,      // 全价
    "rent": 720,         // 每被踩一次收多少
    "mortgage": 20000,
    "group": "old-house",
    "text": "这里写事件文案"
  },
  "owner": null          // 运行时自动填，不要手改
}
```

**平衡参考**：一局 10 个月，地皮每月平均被踩 1.05 次，起点周边/转角约 1.3~1.6 倍。
想让地产在 10 个月内回本，`月租 × 1.05 × 10 ≈ 房价的 12%~18%` 比较合适。

## 三、卡牌

### 加一张机会卡

在 `cards.opportunity.json` 的 `cards[]` 里追加：

```jsonc
{
  "id": "my-card",              // 唯一 id，不能和别的重复
  "deck": "opportunity",
  "name": "涨薪通知",
  "weight": 7,                  // 抽到的相对权重，越大越常见
  "maxCopies": 3,               // 牌堆里最多放几张
  "target": "self",             // self / other / randomOther / richest / poorest
  "timing": "immediate",        // immediate = 抽到即生效
  "text": ["一封邮件，标题里没有一个钱字。"],
  "detail": "工资系数 +15%",
  "effects": [ { "op": "salaryCoefficientDelta", "delta": 0.15 } ],
  "icon": "mail"
}
```

### 可用的效果算子（op）

| op | 参数 | 作用 |
|---|---|---|
| `cash` | `delta` | 现金增减（负数为支出） |
| `deposit` | `delta` | 存款增减 |
| `transferCash` | `target`, `delta` | 与他人转移现金，对手不足额时按实际余额扣 |
| `cashLossRatio` | `ratio` | 损失现金比例（0.25 = 25%） |
| `payRent` | `tileId` | 付当前格子的租金 |
| `rankCheck` | `delta` | 升(+1)/降(-1)职级 |
| `rankCoefficientDelta` | `delta` | 直接改工资系数 |
| `salaryCoefficientDelta` | `delta` | 改加薪系数 |
| `stat` | `key`, `delta` | 改趣味属性：`face`(面子) / `mood`(心情) / `energy`(精力) |
| `passiveIncome` | `delta` | 增加每月被动收入 |
| `livingCostDelta` | `delta` | 永久改生活开销（0.15 = +15%） |
| `loanRateDelta` | `delta` | 改贷款利率 |
| `skipNext` | `count` | 跳过接下来几个回合 |
| `moveTo` | `tileId` | 传送到某格 |
| `loan` | `principal`, `months` | 获得贷款 |
| `repay` | `principal` | 还款 |
| `drawCard` | `deck`, `count` | 抽牌 |
| `none` | — | 纯文案 |

**写错 op 会被校验器拦下**，控制台会打印 `使用了未知 op：xxx`。

### 道具卡（可存手里，回合内使用）

道具用 `grants` 而不是 `effects`：

```jsonc
{
  "id": "coffee",
  "deck": "item",
  "name": "手冲咖啡",
  "weight": 12,
  "maxCopies": 6,
  "timing": "ownTurn",
  "text": ["续命一杯。"],
  "detail": "本回合可重掷骰子 1 次",
  "effects": [],
  "grants": [ { "op": "reroll", "count": 1 } ],
  "icon": "coffee"
}
```

可用 grant：`reroll`（重掷）、`drawCard`（抽牌）、`skipMove`（跳过一次移动）、
`exemptLiving`（本月生活费全免）、`halveLiving`（本月减半）、
`moveBonus`（移动 +N 格）、`skipNext`（跳过下回合）、`shield`（免一次损失）、
`peekRichest`（查看对手资产）、`stat`、`cash`。

## 四、事件池

`events.json` 的 `pools` 按格子类型分组，键名要与 `board.json` 里的 `type` 对应：

```jsonc
"pools": {
  "eat": [
    {
      "id": "eat-bento",
      "weight": 30,                                  // 权重
      "text": ["今天的午饭是公司食堂第九大菜系。"],   // 可多句，随机取一句
      "effects": [ { "op": "cash", "delta": -35 } ],
      "icon": "bento"
    }
  ]
}
```

新增事件池时，键名用格子 type（`eat` / `clothes` / `rent` / `promotion` / `demotion` /
`raise` / `cut` / `vacation` / `company`），或在格子的 `payload.eventPool` 里指定。

## 五、AI 性格

```jsonc
{
  "id": "greedy",
  "name": "贪婪型",
  "weights": {
    "buyProperty": 1.0,     // 购房欲望（最高 1.0）
    "keepCash": 0.15,       // 保留现金欲望
    "deposit": 0.05,        // 存款倾向
    "takeLoan": 0.85,       // 借贷倾向（决定 loanMaxRatio 是否被突破）
    "useItem": 0.75,        // 用道具倾向
    "cardOpportunity": 0.9, // 打机会卡倾向
    "cardFate": 0.55,       // 打命运卡倾向（越高越爱作死）
    "cardItem": 0.7
  },
  "thresholds": {
    "reserveRatio": 0.05,   // 现金预留比例
    "loanMaxRatio": 0.72    // 负债 / 总资产 的上限
  },
  "voice": ["现金为王，杠杆是朋友。"]   // 想在 UI 上显示的话
}
```

改完跑模拟看效果：

```bash
node tools/profile.mjs 400      # 跑 400 局，看三性格胜率与资产画像
```

## 六、改完必做：跑校验

```bash
node tools/verify-core.mjs     # 33 项回归验证（含伪联机哈希一致性）
node tools/profile.mjs 400     # 平衡性检查
node tools/build.mjs           # 重新构建单文件
```

校验会检查：id 唯一性、格子 id 连续（环形移动依赖）、op 是否在白名单、
卡牌数量是否符合配置、职级门槛是否递增。

**联机时所有端必须用同一份数据**，否则回合包哈希校验会失败。

## 七、常见改动示例

### 想让游戏更短

```jsonc
"game": { "maxRounds": 24, "roundsPerMonth": 4 }   // 24 回合 = 6 个月
```

同时建议把房价整体下调（6 个月比 10 个月收入少），或把 `baseSalary` 调高。

### 想加一个格子类型

1. `board.json` 里加一个格子，`type: "coffee"`，给 `grid` 坐标（必须在 11×11 外环上）
2. `events.json` 里加 `"coffee": [ ... ]` 事件池
3. `src/ui/icons.js` 里加配色 `coffee: { bg, fg, emoji }`
4. `schema.js` 的校验器不用改（它不硬编码类型列表）

### 想改地图大小

`board.json` 的 `grid.cols/rows` 要改成 `n`，然后**重排所有 `grid` 坐标**让它落在外环上。
格子数 = `n × 4 - 4`，且 `tiles` 的 `id` 必须是从 0 开始的连续整数。
改完跑 `node tools/check-layout.mjs` 验证。
