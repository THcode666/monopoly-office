# 「大富翁·工位版」UI 概念设计文档

> 版本：v1.1 · 交付给 UI / 视觉设计师的方案稿
> 视觉风格参考：网易《大富翁 11》（Q 版 2.5D 卡通、3D 半俯视棋盘、彩色分地段格子、中央装饰场景）
> 本文档目标：把"工位版"主题（写字楼、会议室、咖啡间、茶水间）与参考图的高完成度视觉范式对齐，输出一份**可直接交付给设计师**的 UI 概念稿。
>
> **v1.1 变更（2026-10-08）**：
> - 中央场景从 6 主题 → **3 主题**（茶水间 / 会议室 / 加班区），覆盖暖色日常/冷色商务/夜色反差三套情绪
> - 角色立绘从"同底换配饰" → **6 职级差异化设计**（实习生/专员/主管/经理/总监/总裁，6 个不同的人）
> - 表情从 6 种 → **7 种**（新增"加班""被 boss 骂"两个工位版独有表情）
> - 新增**专注模式**（§4.4）：F11 一键切换，副屏常驻 / 演示模式 / 低性能设备均可使用

## 1. 设计目标与灵感来源

### 1.1 大富翁 11 视觉范式拆解（来自参考截图）

| 范式 | 大富翁 11 做法 | 工位版如何"接住" |
|---|---|---|
| 棋盘视角 | **3D 半俯视**（约 50°），格子有底座 + 顶面 + 侧边三段 | 同 3D 半俯视；格子按"写字楼楼层平面图"风分色 |
| 地块分类 | 6 色（橙、蓝、绿、紫、红、黄）按地段分 | 改为**写字楼工区色**：研发区（蓝）、会议室区（紫）、咖啡区（咖啡）、高管区（金）、公共区（绿）、机动区（橙） |
| 格子装饰 | 顶面有图标 + 价格 + 等级星标 | 顶面：图标 + 价格 + 拥有等级（★0–★5） |
| 中央区域 | **大型 3D 装饰场景**（奖杯、大象、金塔、龙、帐篷、海岸） | 中央改为**写字楼中庭**：旋转楼梯、共享咖啡机、落地绿植、奖杯台、玻璃天顶 |
| 角色立绘 | Q 版 2.5D，4 人，头身比约 1:2.5，色彩鲜艳 | 6 人：**专员/主管/经理/总监/总裁/实习生**，按职级改剪裁与配饰 |
| 角色状态 | 行走动画 + 表情气泡（笑/哭/惊讶/冒汗/睡） | 同上 + 工位独有表情（加班脸 / 摸鱼脸 / 暴富脸 / 被 boss 骂） |
| 顶部状态 | 星期 + 天数 + 资产柱状图 | 同上：周次 + 当前日 + 团队资产排名柱状图 |
| 右侧玩家面板 | 排名 1–4，头像 + 现金 + 存款 + 道具徽章 | 同上：4 名玩家，头像 + 现金 + 存款 + 道具位（6 格）+ 现金上限 |
| 底部物品栏 | 8 圆形卡槽 + 翻转动画 | 同上：6 圆形卡槽（电风扇 / 奖杯 / 笔记本电脑 / 路灯 / 抱枕 / 彩票 / 停车牌 / U盘 / 咖啡券） |
| 主交互按钮 | 中央"待机"圆按钮 + 右下角"自动"按钮 | 同上：**"掷骰子"** 圆形按钮 + **"自动托管"** 切换按钮 |
| 中央事件弹窗 | 半透明浮层 + 圆形事件卡 + 文案 + 行动按钮 | 同上：圆角矩形卡片 + Q 版插画 + 文案 + 行动按钮 |
| 整体色调 | 高饱和、绿草蓝天、暖光 | 同饱和度偏暖：白墙、原木、咖啡、暖光 |

### 1.2 工位版独有的视觉主张

1. **格子间即格子**——格子不只分色，每格子里嵌"工位道具"（显示器、文件架、便利贴）作为地段识别。
2. **中庭有故事**——中央场景**3 主题轮换**（茶水间 / 会议室 / 加班区），开局随机抽取；叙事节奏跟着场景主题走（茶水间=周中喘息、会议室=季度冲刺、加班区=周末加班）。
3. **立绘会办公**——玩家行走有"西装公文包""高跟鞋""工牌"等职业元素，表情贴近打工人生存状态。**6 职级差异化设计**（不是换配饰，是 6 个不同的人物）：见 §3.5。
4. **道具即办公神器**——道具栏里出现电风扇、咖啡券、团建券、出差报销单、离职金、加班补贴。

### 2.2 字体系统

| 用途 | 字体 | 字号 / 字重 | 备注 |
|---|---|---|---|
| 顶栏大数字 | **思源黑体 Heavy** / 数字用 **DIN Bold** | 32–40px | 天数、倒计时 |
| 玩家名 / 等级 | 思源黑体 Bold | 18–22px | 排名面板 |
| 卡片标题 | 思源黑体 Bold | 24–28px | 事件卡 |
| 卡片正文 | 思源黑体 Regular | 16–18px | 行高 1.5 |
| 按钮 | 思源黑体 Bold | 18–20px | 全大写或首字母大写 |
| 价格 / 数字 | DIN Bold | 16–24px | 千分位空格分隔（`10 000`） |

> 字体后备：`'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif`
> 数字字距：等宽（tabular-nums），保证价格对齐。

### 2.3 图标风格

- **统一语言**：圆角线稿 + 2px 描边 + 一处小色块（不超过图标面积 30%）。
- **大小**：场景内 48–64px，卡槽 64px，HUD 24–32px。
- **地块图标库**（共 16 枚）：

| 区段 | 图标 |
|---|---|
| 研发区 | 🖥️ 显示器 / 💾 服务器机柜 / 🔬 显微镜 / 🧪 烧瓶 |
| 会议室区 | 📊 投影仪 / 🎙️ 麦克风 / 🗓️ 日历 / 📈 走势图 |
| 咖啡区 | ☕ 咖啡杯 / 🍵 茶壶 / 🍰 蛋糕 / 🥐 牛角包 |
| 高管区 | 🏆 奖杯 / 🪑 真皮椅 / 📜 任命书 / 💼 公文包 |
| 公共区 | 🌿 绿植 / 🏃 跑步机 / 📚 书架 / 🛋️ 沙发 |
| 机动区 | ✈️ 飞机 / 🚗 公务车 / 🏨 酒店 / 🎫 出差券 |

- **道具图标**（共 12 枚）：电风扇、奖杯、笔记本电脑、台灯、停车牌、U 盘、咖啡券、加班券、请假条、团建券、报销单、离职金。

### 2.4 光照与质感

- **棋盘主光源**：左上方 30° 暖白光，色温 ~5500K。
- **格子质感**：顶面轻微磨砂（噪点 < 5%），侧面带 1px 高光描边，模拟 ABS 塑料感。
- **中央场景**：半写实 + 卡通描边（cel-shading），整体景深比格子间略浅。
- **角色立绘**：cel-shading 三段明暗（暗 / 中 / 高光），轮廓 2px 深紫描边。
- **事件卡片**：纸感（米白 `#f7f1e1`）+ 1px 投影 + 圆角 16px。
- **粒子**：玩家行走时脚下小灰尘；事件触发时弹出金币 / 闪电粒子。

### 2.5 动效原则

| 元素 | 动效 | 时长 / 曲线 |
|---|---|---|
| 格子高亮（可买） | 边框脉冲 | 1.2s `ease-in-out` 循环 |
| 玩家移动 | 跳跃过格子 | 0.25s/格 `ease-out` |
| 扣款 | 金币飞向左上角 | 0.6s `ease-in` |
| 加薪 | 金币从右上角飞向玩家 | 0.6s `ease-out` |
| 弹窗入场 | 缩放 + 淡入 | 0.25s `cubic-bezier(.34,1.56,.64,1)` |
| 弹窗出场 | 淡出 + 微缩 | 0.15s `ease-in` |
| 排名变化 | 上下滑动换位 | 0.4s `ease-in-out` |
| 骰子 | 旋转 + 渐停 | 1.2s `cubic-bezier(.2,.8,.2,1)` |

### 3.2 各模块详细规范

| 元素 | 位置 | 规格 |

| 周次标签 | 左 24px | 28px Bold，色 `--gold`，背景 `--bg-stage` 半透明 |
| 天数 | 紧邻周次 | 36px Bold DIN 数字，色 `--text-on-dark` |

| 菜单按钮 | 右 96px | 圆形 40px 描边按钮，≡ 图标 |

- 卡片尺寸：260×120，圆角 16px，描边 1px `--border-card`，自身玩家底色 +20% 不透明。
- 现金 / 存款行：16px Regular，💰 / 🏦 小图标 16px。
- 道具行：6 个 24×24 方格，持有填实色，无则空心。

#### ③ 棋盘（中央）

- 网格：11×11，外圈 40 格走子路径 + 中央 9 格装饰（3×3 大场景）。
- 单格：约 100×100px（自适应）。
- 顶面：区段色 + 浅磨砂 + 图标 + 名称（顶部 1 行）+ 价格（底部 1 行）。
- 底座：同色深 30%，高 14px，呈现 3D 感。
- 玩家 token：每格最多 4 人，2×2 网格排列，半径 18px，描边 2px 玩家色。
- 选中态：玩家脚下 1.5× 格大的发光圆环，色 `--gold`，脉冲。

#### ④ 玩家立绘区（左下 200×260）

- 立绘大图：180×240，居中。
- 表情气泡：右上角 64×64 圆角气泡，随状态切换 6 种表情（默认 / 开心 / 惊讶 / 哭泣 / 暴富 / 加班）。
- 等级徽章：左上角 28×28，盾形 + 职级文字（实习生 / 专员 / 主管 / 经理 / 总监 / 总裁）。

#### ⑤ 道具栏（底部居中）

- 8 圆形卡槽，直径 72px，间距 12px。
- 选中态：浮起 8px + 底部 2px `--gold` 描边。
- 未持有：半透明 + 灰色蒙版 + 锁图标。
- 倒序排列：最新获得在最左（动画从右侧滑入）。

#### ⑥ 中央"掷骰子"按钮

- 位置：底部居中（道具栏下方）。
- 圆形 80px，主色 `--gold`，描边 `--gold-deep` 3px。
- 静止态：显示 🎲 图标 + "掷骰子"文字。
- 掷出中：3D 骰子旋转，1.2s。
- 结束后：显示点数 1.2s 后自动收起。

#### ⑦ 自动托管按钮（右下角）

- 胶囊形 86×40，圆角 20px。
- 关闭态：灰底 + "自动"。
- 开启态：绿色 + "托管中"，动画发光脉冲。

### 3.3 棋盘 40 格 + 中央场景

外圈 40 格按上述 6 区段分布，每区段 6–7 格；4 角为特殊格（起点 / 机遇 / 命运 / 监狱 / 总部 等）。

中央 9 格为大场景，每 3×3 一组主题，**3 主题随机抽取**（开局锁定）：

| 主题 | 描述 | 主色调 | 触发语境 |
|---|---|---|---|
| **茶水间** | 咖啡机、沙发、绿植、茶包柜、零食架 | 暖橙 + 浅木（`#e8b97a` / `#d4a268`） | 周中喘息、闲逛买地 |
| **会议室** | 长桌、投影、奖牌墙、白板、落地窗 | 冷蓝 + 深灰（`#5b7eb8` / `#3e4d6e`） | 季度冲刺、大宗交易 |
| **加班区** | 显示器墙、外卖盒、台灯、咖啡杯、便利贴墙 | 夜色暖橙 + 深紫（`#d4824a` / `#2d2845`） | 周末加班、连败翻盘 |

> **轮换意义**：3 主题覆盖**暖色日常 / 冷色商务 / 夜色反差**三套情绪，让每局视觉新鲜感最大化，同时美术工作量控制为 3×3×1 张大图 = 3 张主稿 + 9 个物件变体。

### 3.4 角色立绘规范（6 职级差异化设计）

> 核心：**6 个不同的人**，不是同一个底子换配饰。每个职级有自己的体型、年龄感、气质与专属动作。

#### 3.4.1 设计基线

| 项 | 规范 |
|---|---|
| 头身比 | 1:2.5（Q 版 2.5D） |
| 输出尺寸 | 512×680 PNG（透明） |
| 画风 | cel-shading 三段明暗 + 2px 深紫描边 |
| 姿势 | **每个职级 1 个专属默认动作**（不是统一站姿） |
| 配色 | 主角玩家 1 号用品牌色金（`#f5c842`），其余 5 人用协调色（红/蓝/绿/紫/橙） |

#### 3.4.2 6 职级差异化定位

| # | 职级 | 性别 / 年龄 | 体型 | 服装 | 专属动作 | 默认表情 | 备注 |
|---|---|---|---|---|---|---|---|

## 4. 交互流程说明

### 4.1 总流程

```
启动 → 主菜单 → 选模式 → 角色选择 → 加载场景 → 回合循环 → 结束结算
                                       │
                                       └─ 回合循环：
                                            ① 投骰子 → ② 移动 → ③ 落格判定
                                                       │
                                                       ├─ 空地 → 弹出购买卡片
                                                       ├─ 己方 → 无事
                                                       ├─ 他人 → 付租金弹窗
                                                       ├─ 机遇/命运 → 抽卡弹窗
                                                       ├─ 特殊格 → 事件弹窗
                                                       └─ 监狱 → 选择交赎金/等
                                                       ↓
                                                  ④ 月结算（每 4 回合）
                                                       ↓
                                                  ⑤ 切换下一玩家
```

### 4.2 关键交互细节

| 场景 | 触发 | 用户操作 | 系统反馈 |
|---|---|---|---|
| 掷骰子 | 玩家回合开始 | 点击中央按钮 | 骰子旋转 1.2s → 显示点数 → 玩家跳跃前进 |
| 购买地块 | 落在空地 | 弹窗：买 / 不买 | 买则扣款 + 格子描边变玩家色 + 等级升 ★ |
| 付租金 | 落在他人地块 | 弹窗：自动扣款 | 现金飞向对方 + 双方资产面板同步刷新 |
| 抽卡 | 落在机遇/命运 | 弹窗：卡片翻转动画 | 显示卡面 2s → 应用效果 → 自动关闭 |
| 月结算 | 每 4 回合结束 | 无（自动） | 顶部弹层 + 工资入账 + 资产柱状图重排 |
| 道具使用 | 选中卡槽 + 目标玩家/格子 | 双击或拖拽 | 道具飞向目标 + 应用效果 |
| 自动托管 | 右下角开关 | 点击切换 | AI 自动掷骰/买地/用卡 |
| 破产 | 现金 < 应付款 | 无 | 弹窗：宣告破产 → 转旁观模式 |
| 游戏结束 | 回合数达到上限 或 仅剩 1 人 | 无 | 结算页 + 排名 + 退出按钮 |

### 4.3 状态可视化

| 状态 | 视觉提示 |
|---|---|
| 当前玩家 | 棋盘上头像发光 + 底部"轮到 X"提示条 |
| 可购买 | 格子边框金色脉冲 |
| 不可交互（托管中） | 棋盘整体降饱和度 30% + 半透明蒙层 |
| 暂停 | 顶部灰条 + "已暂停" |

### 4.4 专注模式（Focus Mode）

> 定位：把棋盘当成"桌面常驻 / 副屏装饰"——只留棋盘 + 中央场景，其他全收起。

#### 4.4.1 触发方式

| 方式 | 场景 |
|---|---|
| `F11` 快捷键 | 最快 |
| 顶栏菜单 → 切换专注模式 | 带提示 |
| 设置页 → 启动时进入专注模式 | 默认行为开关 |

#### 4.4.2 视觉效果（对比正常模式）

| 元素 | 正常模式 | 专注模式 |
|---|---|---|
| 顶栏 | 显示（64px） | **收起**（0px） |
| 玩家排名面板 | 显示（280px） | **收起** |
| 玩家立绘区 | 显示（左下 200×260） | **收起** |
| 道具栏 | 显示（8 卡槽） | **收起** |
| 掷骰子按钮 | 显示（80px 金色） | **仅当前玩家可点击时显示 30px 小按钮** |
| 自动托管按钮 | 显示（右下 86×40） | **收起**（专注模式下不允许托管） |
| 棋盘 | 显示 | **铺满整个视口**（最大化） |
| 中央场景 | 显示 | 显示（占视口中心 50%） |
| **当前玩家提示** | 头像发光 + 底部提示条 | **仅保留脚下金色光环** |
| 落格气泡 | 显示 | 显示（必要的信息反馈） |
| 事件弹窗 | 显示 | 显示（必要的中断） |

#### 4.4.3 退出方式

| 方式 | 说明 |
|---|---|
| `F11` / `Esc` | 双键皆可 |
| 棋盘右上角浮出"退出专注"按钮 | 鼠标悬停 1s 后浮现 |

#### 4.4.4 适用场景

1. **副屏常驻**——办公时把游戏挂在副屏，看别人玩或自己后台托管当背景动画
2. **演示模式**——给同事 / 客户讲解时不被 UI 干扰
3. **低性能设备**——减少 DOM 渲染压力，提升帧率
4. **省电模式**——笔记本电池模式下延长续航

#### 4.4.5 实施要点

- 用 CSS class `body.focus-mode` 切换状态，**不重建 DOM**
- 收起动画 0.3s `ease-in-out`，展开动画 0.2s `ease-out`
- 事件弹窗必须能在专注模式下正常弹出（破坏沉浸感但保证可玩性）
- 专注模式下的掷骰子自动改为"按空格掷"（避免鼠标找不到小按钮）

## 7. 设计原则与红线

### 7.1 一致性原则

1. **所有按钮遵循三态**：默认 / Hover（亮度 +10%） / Pressed（缩放 95%）。
2. **所有卡片遵循同一种圆角**：16px（卡片）/ 24px（弹窗）/ 12px（小标签）。
3. **所有文字遵循同一行高**：标题 1.2，正文 1.5。
4. **所有色彩遵循 token**：不允许直接使用 HEX，引入新色须先登记到调色板。

### 7.2 可用性红线

- ❌ 不要在深色背景上用深色文字（最低对比度 4.5:1）。
- ❌ 不要使用 < 12px 的字号（正文最小 16px）。
- ❌ 不要让按钮宽度 < 80px（手机端误触风险）。
- ❌ 不要用纯红 + 纯绿传达"好/坏"（色盲友好：加图标辅助）。
- ✅ 所有交互元素必须有焦点态（键盘 Tab 可达）。
- ✅ 所有破坏性操作（破产 / 强制退出）需要二次确认。

### 7.3 性能红线

- 单张 PNG 素材 ≤ 500KB（中央场景可破例到 2MB）。
- Canvas 绘制元素总数 ≤ 2000 个（参考大富翁 11 的 Z 序管理）。
- 动效帧率 ≥ 30fps（低于 30fps 自动降级到 15fps 简版）。
- 启动时间 ≤ 3s（含启动页动画）。
